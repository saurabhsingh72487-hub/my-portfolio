# ⚙️ Getting Started

Clone the repository

```bash
git clone https://github.com/saurabhsingh72487-hub/my-portfolio.git
```

Move into project

```bash
cd my-portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

# 🚀 Build

```bash
npm run build
```

Start production server

```bash
npm start
```
