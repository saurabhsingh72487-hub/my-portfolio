## Overview

P2P Video Chat is a real-time video communication platform built with WebRTC and Socket.io.

## Key Features

- Real-time peer-to-peer video calling
- Socket.io signaling for offer, answer, and ICE candidates
- STUN/TURN support for restricted networks
- Responsive React interface
