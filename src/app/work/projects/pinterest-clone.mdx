## Overview

Pinterest Clone is a full-stack media-sharing platform where users can upload, manage, and view image-based posts. The project focuses on secure authentication, optimized image handling, and centralized frontend state management.

## Key Features

- **Image upload system**: Integrated Cloudinary for asynchronous image upload and media storage.
- **JWT authentication**: Implemented secure login/session handling and protected routes.
- **Redux state management**: Centralized application state using Redux Toolkit.
- **REST API backend**: Built backend APIs with Express and MongoDB for posts, users, and auth.
- **Responsive UI**: Designed a smooth, mobile-friendly interface for image discovery.

## Technologies Used

- **MongoDB**
- **Express.js**
- **React**
- **Node.js**
- **Cloudinary**
- **JWT**
- **Redux Toolkit**

## Challenges and Learnings

The biggest challenge was handling media-heavy workflows while keeping the user experience smooth. I learned how to manage image uploads with Cloudinary, protect API routes using JWT, and reduce frontend complexity with Redux Toolkit.

## Outcome

The project helped me build a stronger understanding of full-stack social-media architecture, secure REST APIs, media handling, and scalable frontend state management.
